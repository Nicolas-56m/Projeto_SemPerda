# Projeto_SemPerda

## Metodologias utilizadas: Kanban e XP
- O projeto utilizará as metodologias ágeis Kanban e XP (Extreme Programming) para organizar e melhorar o desenvolvimento do software. O Kanban será utilizado para visualizar e acompanhar as tarefas, enquanto o XP ajudará a garantir a qualidade do sistema por meio de testes frequentes, colaboração entre os desenvolvedores e melhoria contínua. Juntas, essas metodologias contribuirão para um desenvolvimento mais organizado, eficiente e com menos erros.

## Explicando o Projeto SemPerdas
- O SemPerdas é um site desenvolvido para ajudar pequenos mercados, padarias, mercearias e restaurantes a controlar seus estoques, reduzir o desperdício de alimentos e evitar prejuízos financeiros causados pelo vencimento dos produtos.
Seu objetivo é facilitar a gestão do estoque, permitindo que os comerciantes acompanhem seus produtos e tomem decisões para evitar perdas.

- O sistema permite cadastrar produtos com nome, quantidade, preço e data de validade. Ele identifica produtos próximos do vencimento ou já vencidos e envia alertas automáticos para que o comerciante possa tomar providências.

## Requisitos Funcionais

- **RF01:** Permitir o cadastro de produtos com nome, quantidade, preço e data de validade.
- **RF02:** Permitir editar as informações dos produtos cadastrados.
- **RF03:** Permitir excluir produtos do estoque.
- **RF04:** Armazenar os dados dos produtos em um banco de dados online.
- **RF05:** Calcular quantos dias faltam para o vencimento de cada produto.
- **RF06:** Exibir alertas para produtos próximos do vencimento ou já vencidos.
- **RF07:** Apresentar uma lista dos produtos cadastrados e suas situações.
- **RF08:** Exibir relatórios e gráficos sobre produtos próximos do vencimento e perdas registradas.
- **RF09:** Calcular o valor estimado dos produtos em risco.
